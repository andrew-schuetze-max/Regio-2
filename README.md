# Regio

Eine moderne, regionale Web-App als MVP für die Darstellung von Services, Orten und Aktivitäten in einer Region.

## Stack

- React
- TypeScript
- Vite
- Supabase-ready client setup

## Schnellstart

1. Abhängigkeiten installieren:
   npm install
2. Umgebungsvariablen optional konfigurieren:
   cp .env.example .env
3. App starten:
   npm run dev
4. Build erzeugen:
   npm run build

## Features

- Region- und Kategorie-Filter
- Übersichts- und Dashboard-Karten
- Mobile-first UI
- Optionales Supabase-Setup für Live-Daten
